ALE from the scratch

Accumulated Local Effects (ALE) plots provide a way to understand how features influence the prediction of a machine learning model, focusing on the local changes within small intervals of the feature values. Unlike Partial Dependence Plots (PDPs) that consider the global average effect of a feature, ALE plots look at the local main effects and are less influenced by correlated features.

ALE Formula for a Single Continuous Feature

The ALE of a single feature (X_s) is calculated as follows:

  1. Partition the Range of (X_s): Divide the range of the feature (X_s) into (K) intervals based on its quantiles or regular intervals, (k = 1, , K). Each interval is denoted as ([x_{s,k}, x_{s,k+1}]).

  2. Calculate the Local Effect within Each Interval: For each interval (k), calculate the difference in the model’s predictions when varying (X_s) within this interval, while keeping all other features fixed. This is done by averaging the partial derivatives of the model’s prediction function with respect to (X_s) over the interval. The local effect for interval (k) is given by:

    [ k = {i:x_{s,i} } ( f(x_{s,i+1}, X_{s}) - f(x_{s,i}, X_{s}) ) ]

    Here, (n_k) is the number of observations in interval (k), (f()) is the prediction function, (x_{s,i}) and (x_{s,i+1}) are consecutive observations of (X_s) in the interval, and (X_{s}) represents all other features.

  3. Accumulate the Local Effects: To get the ALE value at a particular point (x_s) within its interval, accumulate the local effects from the first interval up to the interval that contains (x_s), and then subtract the overall mean to center the ALE values:

    [ (x_s) = _{k=1}^{K(x_s)} k - {k=1}^{K} _k ]

    (K(x_s)) is the interval index that contains (x_s).

Interpretation

  • Local Effects: The ALE plot shows how the prediction changes locally as (X_s) varies, providing insights into the feature’s effect on the model output within specific regions of (X_s).

  • Centering: Subtracting the overall mean centers the ALE values around zero, making the plot easier to interpret. When the ALE value is zero, it indicates that at that specific feature value, the feature’s effect on the prediction is average. Positive or negative ALE values indicate above-average or below-average effects, respectively.

  • Advantages over PDP: ALE plots avoid the pitfalls of PDPs in the presence of correlated features by focusing on local changes and not assuming independence between features.

Implementation Note

Calculating ALE values involves estimating or calculating the partial derivatives of the model’s prediction function, which can be straightforward for some models (like linear regression) but may require numerical approximation for complex models (like random forests or neural networks). In practice, for non-differential models, the difference in predictions (f(x_{s,i+1}, X_{s}) - f(x_{s,i}, X_{s})) serves as a proxy for the derivative, making ALE plots applicable to a wide range of models.

Computing ALE for Categorical Features

Given a categorical feature (X_c) with (N) categories, the steps to compute ALE for (X_c) are as follows:

  1. Compute the Baseline Prediction: Calculate the average prediction across all data points. This serves as the baseline against which the effect of each category will be measured. Denote this average prediction as ({f}).

  2. Category-specific Effect: For each category (n) in (X_c), calculate the average prediction for data points where (X_c = n). Subtract the baseline prediction ({f}) from this average to determine the effect of category (n) relative to the average. This difference represents the local effect of having category (n) versus the average effect of all categories.

  3. Accumulated Effect: The ALE value for a category is simply its computed category-specific effect, as there’s no accumulation process like in the continuous case. ALE values for categorical features are typically centered by subtracting the mean of all category-specific effects so that the ALE effects sum up to zero.

Example and Interpretation

If (X_c) is a categorical feature representing color with categories ({“Red”, “Blue”, “Green”}), and the average predictions for “Red”, “Blue”, and “Green” are higher than the overall average prediction ({f}), the ALE plot will show positive values for these categories. This indicates that items of these colors tend to have higher predicted values compared to the average prediction across all colors.

Practical Considerations

  • Centering: Like with continuous features, ALE values for categorical features are often centered. This means adjusting the ALE values so that their average is zero across all categories, enhancing interpretability by focusing on the deviation from the average effect.
  • Implementation: To implement ALE for categorical features, you can loop over each category to calculate its specific effect and then adjust these effects by their overall mean. This process is typically more straightforward computationally than the ALE computation for continuous features since it doesn’t require estimating derivatives or accumulating effects over intervals.

n <- 200
X1 <- runif(n, -2, 2)
X2 <- rnorm(n)
X_cat <- sample(c("A", "B", "C"), n, replace = TRUE)  # Categorical feature
Y <- X1^2 + sin(X2) + ifelse(X_cat == "A", 1, ifelse(X_cat == "B", -1, 0)) + rnorm(n, sd = 0.1)
data <- data.frame(X1 = X1, X2 = X2, X_cat = as.factor(X_cat), Y = Y)

# Fit a model considering the categorical feature
library(randomForest)
model <- randomForest(Y ~ X1 + X2 + X_cat, data = data)

Step 2: Compute ALE for the Categorical Feature

calculate_ale_categorical <- function(model, data, feature) {
  categories <- levels(data[[feature]])
  overall_mean <- mean(predict(model, newdata = data))
  
  ale_values <- sapply(categories, function(cat) {
    cat_data <- data[data[[feature]] == cat, ]
    cat_mean <- mean(predict(model, newdata = cat_data))
    cat_mean - overall_mean
  })
  
  names(ale_values) <- categories
  return(ale_values)
}

# Calculate ALE for the categorical feature X_cat
ale_values_cat <- calculate_ale_categorical(model, data, "X_cat")

# Print the ALE values for each category
print(ale_values_cat)

Explanation

  • This function computes the ALE values for a categorical feature by first calculating the overall mean prediction across all data.
  • Then, for each category, it calculates the mean prediction for observations within that category and computes the difference from the overall mean prediction.
  • The resulting ALE values represent the local effect of each category on the model’s predictions relative to the average effect across all observations.

How ALE Plots for Categorical Features Work:

  • Grouping by Category: Instead of creating intervals as in continuous features, the dataset is grouped by the categories of the feature.
  • Calculating Differences: For each category, calculate the difference between the average prediction for observations within that category and the overall average prediction across the entire dataset.
  • Accumulated Effect: The ALE value for each category is the calculated difference, showing the local effect of each category on the prediction.

Implementation for Categorical Features:

Let’s say we have a model and a categorical feature X_cat in our dataset. The following is a simplified R implementation for computing and plotting ALE for a categorical feature:

library(ggplot2)

# Assuming 'model' is your trained model, and 'data' is your dataset
# 'X_cat' is the name of the categorical feature, and 'Y' is the target variable

# Calculate the overall average prediction
overall_avg_pred <- mean(predict(model, newdata = data))

# Calculate average prediction for each category
cat_avgs <- aggregate(predict(model, newdata = data) ~ data[[X_cat]], FUN = mean)
colnames(cat_avgs) <- c("Category", "Avg_Pred")

# Calculate the ALE values (difference from the overall average)
cat_avgs$ALE <- cat_avgs$Avg_Pred - overall_avg_pred

# Plotting the ALE values for each category
ggplot(cat_avgs, aes(x = Category, y = ALE, fill = Category)) +
  geom_bar(stat = "identity") +
  theme_minimal() +
  labs(title = "ALE Plot for Categorical Feature X_cat",
       x = "Category",
       y = "Accumulated Local Effect")

Interpretation:

  • ALE Value Significance: Positive ALE values indicate that a category has a higher than average effect on the model’s predictions, whereas negative ALE values suggest a lower than average effect.
  • Comparing Categories: By comparing the ALE values across categories, you can identify which categories are most and least influential in affecting the model’s output.
  • Impact on Decision Making: Understanding how each category influences predictions can help in decision-making processes, such as targeting specific groups more effectively or identifying biases in model predictions.

Considerations:

  • Reference Level: For linear models or models that inherently treat one category as a reference (intercept), the ALE values should be interpreted in relation to this reference. The effect of the reference category is typically normalized to zero.
  • Model Complexity: For more complex models, such as ensemble methods or neural networks, the interpretation of ALE plots remains the same, but the insights can be more nuanced due to interactions and nonlinear effects captured by the model.

ALE plots for categorical variables provide a straightforward and interpretable way to assess the impact of each category on model predictions, enhancing model transparency and aiding in the interpretation of complex machine learning models.
